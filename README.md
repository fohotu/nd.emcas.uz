# Внутренний реестр документов

Веб-приложение для **централизованного хранения, структурирования и управления внутренними документами организации**.

Система позволяет организовать документы по категориям и разделам, быстро находить нужную информацию, просматривать документы и управлять доступом к ним.

## Основные возможности

- 📁 Иерархическая структура категорий и разделов
- 📄 Добавление и хранение документов
- 🔎 Поиск документов и категорий
- 👁 Просмотр документов
- ⬇️ Скачивание файлов
- ✏️ Редактирование информации о документах
- 🗂 Организация документов по категориям
- 🔐 Авторизация пользователей
- 👤 Управление доступом пользователей
- 📋 Работа с метаданными документов

## Установка

Клонировать проект:

```bash
git clone <repository-url>

cd <project-directory>
```

Установить PHP-зависимости:

```bash
composer install
```

Установить frontend-зависимости:

```bash
npm install
```

Создать файл конфигурации:

```bash
cp .env.example .env
```

Сгенерировать ключ приложения:

```bash
php artisan key:generate
```

Настроить подключение к базе данных в `.env`.

Пример:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=document_registry
DB_USERNAME=root
DB_PASSWORD=
```

Запустить миграции:

```bash
php artisan migrate
```

При необходимости заполнить базу тестовыми данными:

```bash
php artisan db:seed
```

Создать symbolic link для файлов:

```bash
php artisan storage:link
```

Запустить frontend:

```bash
npm run dev
```

Запустить Laravel:

```bash
php artisan serve
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## Работа с документами

Документы организованы в виде иерархической структуры:

```text
Реестр документов
│
├── Нормативные документы
│   ├── Законы
│   ├── Постановления
│   └── Приказы
│
├── Внутренние документы
│   ├── Инструкции
│   ├── Регламенты
│   └── Положения
│
└── Техническая документация
    ├── Проекты
    ├── Отчёты
    └── Инструкции
```

Каждый документ может содержать:

- название;
- категорию;
- описание;
- файл;
- дату создания;
- дату изменения;
- автора;
- дополнительные параметры.

## Поиск

Система предоставляет возможность быстрого поиска документов по названию и другим доступным параметрам.

Поиск позволяет пользователю быстро найти нужный документ даже при большом количестве записей в реестре.

## Хранение файлов

Загруженные документы хранятся в файловом хранилище приложения.

Для публикации файлов Laravel используется:

```bash
php artisan storage:link
```
